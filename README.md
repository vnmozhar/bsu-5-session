# Дэшборд учебной сессии

Адаптивное React-приложение на Vite и Ant Design. Публичные данные вручную курируются в `src/data/publicSubjects.ts`: предварительные даты сессии, форматы аттестации, общие сведения о курсе, преподаватели и проверяемые ссылки.

## Локальный запуск

```sh
npm install
npm run dev
```

Для production-сборки и локальной проверки типов:

```sh
npm run build
```

## Публикация на Vercel

- Root Directory: `workspace/projects/session-dashboard`
- Build Command: `npm run build`
- Output Directory: `dist`
- Framework Preset: Vite

Приложение не загружает данные из архива заметок. Все даты и требования должны иметь отметку об источнике и статусе подтверждения; предварительное расписание нельзя привязывать к предмету или группе без подтверждения. Не добавляйте личные планы и прогресс, сведения о личных заданиях и работах, оплате и задолженностях, персональные ссылки или закрытые материалы. Ссылки на порталы и материалы включайте только если они предоставлены и предназначены для публикации. Для предметов без разрешенной ссылки отображается пометка, что ссылка не добавлена.
