# Дэшборд учебной сессии

Адаптивное React-приложение на Vite и Ant Design. Публичные данные вручную курируются в `src/data/publicSubjects.ts` и `src/data/officialSchedule.ts` с указанием источника.

## Источники и согласованность данных

`src/data/officialSchedule.ts` - единый источник расписательных фактов: даты, время, типы событий, группы, преподаватели, аудитории и подтвержденные изменения. Эти данные используются в календарях, недельном расписании и PDF, разделе «Что в сессии», карточках предметов и календарях страниц предметов.

`src/data/publicSubjects.ts` содержит проверенные сведения о курсе, требованиях, материалах, ссылках и других данных, которые не выводятся из расписания. Список карточек объединяет предметы из этого файла и предметы, встречающиеся только в расписании; для каждого расписательного предмета доступна отдельная страница с календарем. При выборе СПС или ХОЗ специализированные карточки и события другой группы скрываются, общие остаются доступными.

При обновлении расписания нужно проверять все зависящие от него представления и руководство пользователя. Если источники расходятся, не исправляйте значение догадкой: сохраните подтвержденную пользователем поправку или явно отметьте необходимость уточнения.

Рабочие правила описаны в [инструкции для файлов дэшборда](../../../.github/instructions/session-dashboard.instructions.md); для сквозного обновления или проверки используйте агента [Session Dashboard Maintainer](../../../.github/agents/dashboard-maintainer.agent.md).

## Визуальная тема

Токены палитры и типографики находятся в `src/theme.css` и подключаются из `src/main.tsx`. Файл основан на CSS-токенах, предоставленных для оформления сайта юридического факультета БГУ. Стили дэшборда используют CSS-переменные, а компоненты Ant Design настроены на ту же палитру.

## Расписание сессии

Расписание занятий и промежуточной аттестации 4 курса заочной формы на 2026/2027 учебный год хранится в `src/data/officialSchedule.ts` и показывается во всех расписательных представлениях. Аудитории добавлены по обновленному расписанию; для международного частного права группы ХОЗ 21 ноября 2026 года применена подтвержденная пользователем аудитория 316 вместо ошибочной в документе. Группа 1 исходного расписания сопоставлена фильтру СПС, группа 2 - фильтру ХОЗ; соответствие подтверждено пользователем.

В календарях главной страницы и страницы предмета цветные метки различают типы событий. Над календарем доступны флажки множественного выбора типов с такими же цветовыми маркерами; выбранный тип получает соответствующую цветную рамку и мягкую заливку. Кнопка «Показать все» возвращает полный список. При выборе даты тип каждого события явно подписан в карточке.

Изменения расписания помечаются значком `!` в календаре и подписью с прежним и новым временем в сведениях о событии. Для судебной экспертизы 19 ноября 2026 года указано новое время 09:00 вместо 09:30 по сообщению пользователя.

Страница полного расписания показывает одну неделю в сетке дней и времени; короткие события получают увеличенную визуальную высоту, сохраняя исходное время. Переносы выделены отдельной пометкой. Навигация подписана действиями перехода между неделями и возврата к текущей. Экспорт формирует PDF формата A4 в портретной ориентации для открытой недели с учетом выбранной группы и типов событий, группирует расписание по дням и включает аудитории, если они указаны; изменения времени включают прежнее время в строку события.

В разделе «Что в сессии» для каждой дисциплины выводятся дата, время и группа зачета или экзамена по выбранной группе; если аттестация для фильтра не указана в расписании, это явно отмечается.

На странице аграрного права рядом со ссылкой на учебный портал можно раскрыть код записи на курс и скопировать его. Сначала войдите на портал под своей учетной записью, затем используйте код для записи на курс.

## Руководство пользователя

Ссылка «Руководство пользователя» в заголовке календаря главной страницы скачивает форматированное PDF-руководство из `public/user-guide-session-schedule.pdf`. Исходный PDF и его SHA-256 записаны в архиве проекта сессии.

## Локальный запуск

```sh
npm install
npm run dev
```

Для production-сборки и локальной проверки типов:

```sh
npm run build
```

## Публикация на Vercel

- Root Directory: `.`
- Build Command: `npm run build`
- Output Directory: `dist`
- Framework Preset: Vite

The website-only GitHub repository has the app files at its root, so set Root Directory to `.`. `vercel.json` rewrites direct requests to subject pages and `/schedule` to the SPA entry point.

Приложение не загружает данные из архива заметок. Все даты и требования должны иметь отметку об источнике и статусе подтверждения; предварительное расписание нельзя привязывать к предмету или группе без подтверждения. Общие требования предмета и типы работ можно публиковать, но не личный статус выполнения, индивидуально назначенные темы, личные заметки и прогресс, оплату и задолженности, персональные ссылки или закрытые материалы. Анализ и предположения маркируются как таковые. Ссылки на порталы и материалы включайте только если они предоставлены и предназначены для публикации. Для предметов без разрешенной ссылки отображается пометка, что ссылка не добавлена.

## Публичные материалы

Файлы из `public/materials/` входят в сборку Vite и доступны любому посетителю сайта по прямой ссылке. Авторизация и ограничение скачивания не настроены. Включайте только конкретные учебные материалы, одобренные для публикации; не копируйте в эту папку весь архив, личные работы, расписания или заметки. Пользователь подтвердил права на публикацию включенных учебных материалов. Для переданных нормативных текстов в интерфейсе отдельно указано, что актуальность редакций не проверена.

Ссылки на файлы и подписи к ним хранятся в `src/data/publicSubjects.ts` в материалах соответствующего предмета.
